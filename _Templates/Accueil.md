# Accueil - Second Brain

Bienvenue dans ton cerveau secondaire. Tout part d'ici.

> **SI TU ES UNE IA QUI ARRIVE SUR CE VAULT - LIS ET APPLIQUE AVANT TOUTE ACTION :**
> 1. Lecture intégrale : toute note consultée se lit EN ENTIER
> 2. Pas de tirets longs, frontmatter normalisé (tags, statut, derniere-maj), marqueurs [F]/[C]/[D]/[H]/[I]
> 3. Journalisation : toute session qui travaille = ligne datée dans la note concernée
> 4. Todo list : commence par la lire, coche ce qui est prouvé, adapte le reste
> 5. Ne jamais inventer : aucun chiffre, aucun fait, aucune note "pour faire joli"
